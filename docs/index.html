Build it yourself

Couch Potato is open source. Grab the code, fire up Xcode, and grow your own spud in a few minutes.

What you'll need

  • Xcode 26 or newer
  • iOS 18 / iPadOS 18 or macOS 15 to run it
  • XcodeGen to generate the project
  • A snack. Non-negotiable.

  1. Install XcodeGen

    brew install xcodegen

  2. Clone the repo

    git clone https://github.com/nearbycoder/couch-potato

  3. Hop into the folder

    cd couch-potato

  4. Generate the Xcode project

    xcodegen

  5. Open it and hit Run

    open CouchPotato.xcodeproj

    Pick an iPhone, iPad or “My Mac” destination and press ⌘ R.

🧈 Optional extra butter: Couch Potato works out of the box using TVmaze and Apple's iTunes charts. For full movie search and availability across every provider, grab a free API key from TMDB and paste it into Settings → Data Sources in the app.
